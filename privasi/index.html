Kebijakan Privasi

AI Tahfiz · berlaku sejak 29 Oktober 2026 · diperbarui 31 Oktober 2026

Ringkasnya:
  • AI Tahfiz tidak memiliki server untuk data pengguna, tidak memakai akun, iklan, analitik, maupun pelacak.
  • Progres hafalan, penanda, dan pengaturan hanya tersimpan di perangkat Anda.
  • Saat fitur mikrofon dipakai, suara Anda diproses oleh layanan pengenal suara browser (di Chrome: Google). AI Tahfiz tidak merekam atau menyimpan suara.

1. Tentang aplikasi ini

AI Tahfiz adalah aplikasi untuk membantu menghafal Al-Qur'an: membaca mushaf, menyetor bacaan dengan suara, dan murajaah terjadwal. Aplikasi tersedia sebagai situs web di https://tahfiz.lifeos.web.id dan sebagai aplikasi Android (id.aitahfiz.app) yang membuka situs yang sama melalui Chrome. Kebijakan ini berlaku untuk keduanya.

2. Data yang disimpan di perangkat Anda

Data berikut disimpan di penyimpanan browser pada perangkat Anda dan tidak dikirim ke pengembang:

  • Status hafalan per ayat, jadwal murajaah, dan catatan aktivitas harian (untuk statistik dan hari beruntun).
  • Penanda (bookmark) dan posisi bacaan terakhir.
  • Pengaturan, misalnya target harian, qari, ukuran huruf, tema, dan kepekaan pencocokan suara.
  • Salinan teks surah yang sudah dibuka atau diunduh, agar bisa dibaca tanpa internet.

Teks hasil transkripsi suara hanya disimpan sementara di memori selama sesi dan hilang saat halaman ditutup atau surah diganti.

3. Mikrofon dan pengenalan suara

  • Mikrofon hanya dipakai setelah Anda menekan tombol mikrofon, dan browser akan meminta izin Anda terlebih dahulu. Izin bisa dicabut kapan saja di pengaturan situs browser.
  • AI Tahfiz memakai fitur pengenalan suara bawaan browser (Web Speech API). Pada Google Chrome, suara Anda dikirim ke server Google untuk diubah menjadi teks, dan tunduk pada Kebijakan Privasi Google.
  • AI Tahfiz hanya menerima teks hasil transkripsi untuk dicocokkan dengan teks ayat. AI Tahfiz tidak merekam, menyimpan, atau mengirim rekaman suara ke pihak mana pun.
  • Hasil pencocokan adalah perkiraan dan bukan penilaian tajwid.

4. Layanan pihak ketiga yang dihubungi perangkat Anda

Untuk menampilkan konten, perangkat Anda terhubung langsung ke layanan berikut. Seperti umumnya permintaan internet, layanan tersebut dapat menerima alamat IP dan informasi teknis browser Anda.

5. Ekspor dan impor

Fitur ekspor membuat file JSON berisi progres Anda, yang disimpan di perangkat Anda sendiri. Fitur impor membaca file yang Anda pilih secara lokal. Tidak ada yang diunggah ke server.

6. Menghapus data

  • Di aplikasi: Progres → Hapus progres.
  • Atau hapus data situs tahfiz.lifeos.web.id di pengaturan browser, atau copot pemasangan aplikasi Android lalu hapus data situs di Chrome.

Karena pengembang tidak menyimpan data Anda di server, tidak ada data di sisi pengembang yang perlu dihapus.

7. Anak-anak

Aplikasi ini dapat digunakan oleh anak-anak dengan pendampingan orang tua atau guru. AI Tahfiz tidak meminta data pribadi seperti nama, email, atau nomor telepon, dan tidak menampilkan iklan. Fitur mikrofon tunduk pada izin browser sebagaimana dijelaskan di bagian 3.

8. Keamanan

Aplikasi hanya disajikan melalui HTTPS. Data di perangkat Anda dilindungi oleh mekanisme keamanan browser dan sistem operasi; siapa pun yang dapat membuka perangkat Anda dapat melihat progres di aplikasi.

9. Perubahan kebijakan

Kebijakan ini dapat diperbarui bila cara kerja aplikasi berubah, misalnya jika kelak ditambahkan akun atau sinkronisasi. Tanggal berlaku di bagian atas halaman akan diperbarui, dan perubahan penting akan diumumkan di aplikasi.
